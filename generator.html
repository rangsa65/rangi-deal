🛒 랑이 특가 자동화

상품 정보만 넣으면 카톡방·스레드용 홍보 글을 만들어 줘요. 입력한 내용은 이 기기에만 저장돼요.

🔵 토스 쉐어링크 🟠 쿠팡 파트너스 ⏰ 쿠팡 골드박스 🧵 스레드 📖 사용법
📖 사용법

1. 상품 담기 (자동)

  1. 맨 위 🔵 토스 / 🟠 쿠팡 / ⏰ 골드박스 버튼으로 사이트를 열어요. (평소 크롬에 로그인된 그대로 열려요)
  2. 토스: 상품의 [링크 발급] → 상품명·판매가·원래 가격·링크가 자동으로 담겨요.
  3. 쿠팡 파트너스: 상품 사진 위 [링크 생성] → 다음 화면 [URL 복사] → 자동으로 담겨요.
  4. 쿠팡 골드박스: 상품마다 붙은 [🛒 담기] → 이 앱에서 그 상품의 [🔗 링크 만들기] → 열린 화면에서 [URL 복사].
  5. 담은 상품은 2초 안에 이 앱 ② 보관함에 나타나요. 같은 상품은 두 번 안 담겨요.
  6. 상품 사진도 자동으로 같이 담겨요. 사진이 없거나 바꾸고 싶으면 [📷 사진 넣기].

2. 카톡방에 올리기

  1. 상품의 [💬 카톡용 사진+글 복사] → 사진이 먼저 복사돼요. (여러 개는 [💬 카톡용 전체 모음 복사] → 사진이 한 장으로 모여요)
  2. 카톡 입력칸에 Ctrl+V → 사진 보내기.
  3. 이 앱 창을 한 번 누르면 글이 자동으로 복사돼요 → 카톡에 Ctrl+V → 보내기.

3. 스레드에 올리기

  1. 🧵 스레드용 칸에서 유형(가격 증거형·공감형…)을 고르고 [🧵 스레드용 사진+글 복사] → 사진이 먼저 복사돼요.
  2. 스레드 글쓰기 칸에 Ctrl+V → 사진 붙이기 → 이 앱 창을 한 번 누르면 글이 복사돼요 → 다시 Ctrl+V.
  3. 또는 [🧵 스레드에 바로 올리기] → 글이 채워진 글쓰기 창이 열려요 → Ctrl+V 하면 사진이 붙어요.
  4. 내용 확인 후 [게시] → 이 앱 [📋 첫 댓글 복사] → 댓글 칸에 Ctrl+V.

4. 폴센트 (가격 많이 떨어진 쿠팡 상품)

  1. 폴센트에서 상품명·가격이 들어간 글을 복사해 이 화면에 Ctrl+V → 보관함에 담겨요.
  2. [🔗 쿠팡에서 링크 만들기] → 상품명이 복사된 채로 파트너스가 열려요 → 검색창에 Ctrl+V → 같은 상품 [링크 생성] → [URL 복사] → 자동으로 연결돼요.
  3. 폴센트 링크(fcnt.link)는 폴센트의 수익 링크라 쓰지 않아요. 꼭 내 쿠팡 링크로 바꿔서 올려요.

알아두기

  • 가격이 비어 있으면 ⚠️ 가격 확인 필요가 떠요. ✏️ 로 넣어주세요.
  • 다른 데서 복사한 링크 글은 이 화면에서 Ctrl+V 만 하면 바로 채워져요.
  • PC와 휴대폰에 담은 상품은 따로 저장돼요.
  • ⚠️ 지금은 크롬 확장 프로그램과 연결이 안 돼 있어요. 확장 프로그램이 켜져 있는지 확인해 주세요.

1. 상품 담기

  1. 토스 앱 (가장 편해요): 상품 → 공유 → 목록에서 랑이 특가 자동화 → 상품명·링크가 채워지고 판매가 칸으로 이동 → 가격 넣고 [보관함에 담기].
  2. 쿠팡·토스 웹: 맨 위 버튼으로 사이트 열기 → [링크 생성 → URL 복사] (토스는 [링크 발급]) → 이 앱 📥 붙여넣기로 담기 칸을 길게 눌러 붙여넣기 → 자동으로 채워져요 → 가격 넣고 [보관함에 담기].
  3. 휴대폰에서는 가격이 자동으로 안 들어가요. 판매가(원래 가격도 있으면)를 직접 넣어주세요.
  4. 폴센트 앱 (가격 많이 떨어진 쿠팡 상품): 상품 → 공유 → 랑이 특가 자동화 → 상품명·가격이 보관함에 담겨요 → [🔗 쿠팡에서 링크 만들기] → 파트너스 검색창을 길게 눌러 붙여넣기(상품명이 복사돼 있어요) → 같은 상품 [링크 생성] → [URL 복사] → 이 앱으로 돌아와 📥 붙여넣기 칸에 붙여넣기 → 그 상품에 내 링크가 연결돼요.
  5. 폴센트 링크(fcnt.link)는 폴센트의 수익 링크라 쓰지 않아요.

2. 상품 사진 넣기

  1. 상품의 [📷 사진 넣기] → 갤러리에서 상품 사진을 골라요.
  2. 사진은 쿠팡·토스·폴센트 앱에서 상품 사진을 길게 눌러 저장하거나 화면 캡처해 두면 돼요.

3. 카톡방에 올리기

  1. 상품별 [📤 카톡용 사진+글 공유] 또는 [📤 카톡용 전체 모음 공유].
  2. 공유 목록에서 카카오톡 → 내 특가방 선택 → 보내기.
  3. 카톡에 사진만 갔으면, 글은 복사돼 있으니 대화창을 길게 눌러 붙여넣기 → 보내기.

4. 스레드에 올리기

  1. 사진과 같이: [📤 스레드용 사진+글 공유] → 공유 목록에서 Threads → [게시].
  2. 글만: [🧵 스레드에 바로 올리기] → 스레드 앱이 본문이 채워진 채로 열려요 → [게시].
  3. 이 앱 [📋 첫 댓글 복사] → 올린 글의 댓글 칸을 길게 눌러 붙여넣기 → 카톡방 링크가 첫 댓글로 들어가요.

알아두기

  • 공유 목록에 랑이 특가 자동화가 안 보이면 공유창 끝의 더보기를 눌러보세요.
  • 휴대폰과 PC에 담은 상품은 따로 저장돼요.

📥 붙여넣기로 담기

토스·쿠팡에서 복사한 링크 글을 붙여넣으면 상품명과 링크를 아래에 채워 줘요. 휴대폰에 앱으로 설치하면 토스 앱의 공유 목록에서 바로 보낼 수 있어요.
